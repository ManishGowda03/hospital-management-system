# 🏥 Hospital Management System

A full-stack MERN Hospital Management System developed to manage healthcare operations including patients, doctors, appointments, treatments, hospitals, blogs, and administrative workflows.

---

## 🚀 Live Demo

🔗 Frontend: https://hospital-management-system-zeta-eight.vercel.app

🔗 Backend API: https://hospital-4lps.onrender.com

---

# 📌 Features

## 👨‍⚕️ Patient Management

* Add, update, delete patients
* View patient details
* Pediatric patient support

## 🩺 Doctor Management

* Add and manage doctors
* Doctor specialization handling
* Doctor profile management

## 📅 Appointment System

* Appointment scheduling
* Appointment management
* Appointment status tracking

## 💊 Treatment Management

* Add treatments and diagnosis
* Treatment records management
* Treatment cost tracking

## 🏥 Hospital Management

* Hospital CRUD operations
* Hospital information management

## 🩸 Blood Bank Management

* Blood group management
* Blood availability tracking

## 📝 Blog Management

* Create healthcare blogs
* Blog categories and tags
* SEO fields support
* Image uploads using Multer

## 🔐 Authentication & Authorization

* JWT Authentication
* Role-based access control
* Protected routes

## 📱 Responsive Design

* Mobile-friendly UI
* Desktop responsive layout
* Dashboard design using Tailwind CSS

---

# 🛠️ Tech Stack

## Frontend

* React.js
* Axios
* Tailwind CSS

## Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* Multer
